# ✅ Task Manager

A JavaScript task-management application demonstrating CRUD-style interactions, filtering and browser persistence.

## 🚀 Features
- Add tasks
- Set task priority
- Mark tasks as completed
- Delete tasks
- Filter all/active/completed tasks
- Persist tasks with LocalStorage

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage
